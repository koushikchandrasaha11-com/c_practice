# C++ Interview Practice

A collection of C++ programs and problem-solving exercises created while preparing for technical interviews and software engineering placements.

## Topics Covered

- Arrays and vectors
- Conditional statements and loops
- Searching and sorting
- Functions and recursion
- Data structures and algorithms

## Problems Solved

| Problem | Concepts | Complexity |
|---|---|---|
| Second Largest Distinct Element | Arrays, vectors, loops | O(n) time |

## How to Run

Compile a program using GCC:

```bash
g++ second_largest.cpp -o second_largest
```

Run it on Windows PowerShell:

```powershell
.\second_largest.exe
```

## Goal

Practise C++ consistently, improve problem-solving skills, and prepare for coding interviews.

This repository is updated as I solve and learn new problems.
