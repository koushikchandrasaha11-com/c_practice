# C++ Interview Practice

A collection of C++ programs for coding interview preparation.

## Problems Solved

- Second Largest Distinct Element — Arrays, vectors, and loops.
- Valid Parentheses — Strings, stacks, and bracket matching.

## Topics to Practise

- Arrays and strings
- Searching and sorting
- Stacks and queues
- Recursion
- Data structures and algorithms

## Goal

Improve C++ problem-solving skills and prepare for coding interviews through consistent practice.
